# Windows 빌드·확인 체크리스트

이 브랜치는 Linux 샌드박스에서 **컴파일까지만** 검증했습니다(자세한 내용은
`docs/BUILD-VERIFICATION.md`). 아래 순서대로 Windows에서 확인해 주세요.
예상 소요: 15~25분.

## 0. 준비
- [ ] Windows 10/11 x64, Wi-Fi 어댑터 연결
- [ ] Windows 설정 > 개인 정보 및 보안 > 위치 = 켬 (주변 AP 검색에 필요)
- [ ] 저장소를 이 브랜치로 받았는지 확인: `git log --oneline -1` → `design/premium-ui`

## 1. 빌드
```powershell
.\build.bat
```
- [ ] `WifiSignalChecker.exe`, `WifiCoveragePlanner.exe` 두 파일이 만들어졌다
- [ ] 경고 0건에 가깝다(공통 파일에서 `CS0649` 미사용 필드 경고가 날 수 있으며 무해)

## 2. 신호 체크 — 첫 실행
- [ ] 창이 뜨고 배경이 **다크 차콜**(#0B0E13)이다. 흰 화면이면 이전 exe를 실행한 것
- [ ] 상단 탭 4개(실시간/세션/채널/설정)가 보이고 클릭 시 내용이 바뀐다
- [ ] 좌상단 히어로 카드: SSID, 큰 dBm 숫자, 등급 칩, 우측에 5단 막대
- [ ] 값이 1초마다 바뀌어도 **숫자의 오른쪽 끝이 흔들리지 않는다**
- [ ] dBm 숫자가 바뀔 때 부드럽게 이동한다(모션 켜짐 상태)
- [ ] 품질 링이 채워지고 측정 중 은은하게 빛난다
- [ ] KPI 4개(채널/링크/응답/손실)에 스파크라인이 그려진다

## 3. 신호 체크 — 그래프·표
- [ ] 신호 추이 그래프가 곡선으로 부드럽게 그려지고 영역이 그라데이션으로 채워진다
- [ ] 그래프에 마우스를 올리면 세로 십자선과 값 말풍선이 뜬다
- [ ] `1분/3분/5분/10분` 탭을 바꾸면 창 길이가 바뀐다
- [ ] 주황 점선(약전계)이 표시된다
- [ ] 주변 네트워크 표에서 헤더(신호)를 클릭하면 정렬 순서가 바뀌고 화살표가 표시된다
- [ ] 검색 상자에 SSID 일부를 입력하면 즉시 걸러진다
- [ ] `전체/2.4G/5G/6G` 필터가 동작한다
- [ ] 연결된 AP 행에 액센트 점이 붙고 굵게 표시된다
- [ ] 신호 열 옆 "세기" 막대가 신호에 따라 길이가 다르다

## 4. 신호 체크 — 기능
- [ ] 탭 `채널`: 대역(2.4/5/6GHz)을 바꾸면 스펙트럼과 권장 채널이 갱신된다
- [ ] `채널 순위` 표에 채널/점유/AP/최강신호/판정이 나온다
- [ ] 탭 `세션`: 최고·최저·평균·변동성, 등급별 체류 비율 막대가 보인다
- [ ] `세션 저장`으로 CSV를 저장하고, `세션 열기`로 다시 열면
      신호 추이에 **점선**이 겹쳐 나타난다
- [ ] `요약 CSV`가 저장되고 Excel에서 한글이 깨지지 않는다
- [ ] `비우기` 후 표본이 0이 된다(측정은 계속)
- [ ] 탭 `설정`: 측정 주기/스무딩/약전계 기준/창 길이/모션/자동 기록을 바꾸고
      `설정 저장` → 앱을 껐다 켜도 유지된다
- [ ] `%APPDATA%\WifiSurveyTools\checker.ini` 파일이 생겼다
- [ ] 모션을 끄고 저장하면 값이 즉시 바뀌고(애니메이션 없음) CPU 사용이 준다
- [ ] `Ctrl+E`(화면 PNG), `Ctrl+S`(세션 저장), `F5`(스캔), `1~4`(탭) 동작

## 5. 음영 분석기 — 첫 실행
- [ ] 예제 도면이 자동으로 열리고 히트맵이 **좌→우로 채워진다**
- [ ] 상단 KPI(커버리지·음영·분석면적·AP/실측)에 숫자가 뜬다
- [ ] 왼쪽 아이콘 레일에서 도구를 바꾸면 활성 표시(액센트 바)가 이동한다
- [ ] 마우스를 올리면 툴팁이 뜬다
- [ ] AP 마커에서 주기적으로 링이 퍼진다(모션 켜짐)
- [ ] AP를 드래그하면 히트맵이 약 0.1초 뒤 다시 계산되어 부드럽게 갱신된다
- [ ] 왼쪽 아래 부유 범례에 그라데이션·눈금·약전계 스와치가 보인다
- [ ] 오른쪽 `분석 결과` 링과 숫자가 채워진다
- [ ] `선택한 AP`에서 이름/높이/출력을 바꾸면 히트맵이 갱신되고 `Ctrl+Z`로 되돌아간다

## 6. 음영 분석기 — 파일·리포트
- [ ] `파일 > 도면 이미지 불러오기`(Ctrl+I) → 축척 도구로 전환되고 안내가 뜬다
- [ ] 두 점을 눌러 실제 거리를 입력하면 도면 크기가 바뀐다
- [ ] `파일 > 프로젝트 저장`(Ctrl+S) 후 다시 열면 AP·벽·실측이 유지된다
- [ ] `파일 > 리포트(HTML + PNG + CSV)` → 폴더에 3개 파일이 생긴다
- [ ] HTML 리포트를 브라우저로 열면 KPI·히트맵·AP 표가 보이고
      인쇄(Ctrl+P)로 PDF 저장이 가능하다
- [ ] `파일 > 결과 이미지(PNG)`도 정상 저장
- [ ] `--selftest` 실행:
```powershell
.\WifiCoveragePlanner.exe --selftest .\test-output
```
- [ ] `test-output\selftest.txt`에 `ALL PASSED`가 있다
      (Wi-Fi 어댑터가 없으면 실측 항목만 실패할 수 있음 — 원래부터 있던 시험)

## 7. 마무리
- [ ] 150% 배율(설정 > 디스플레이)에서도 글자와 박스가 겹치지 않는다
- [ ] 창을 최소 크기(약 1024×720)까지 줄여도 카드가 겹치지 않는다
- [ ] 노트북 배터리 모드에서 유휴 시 CPU 사용률이 1~3% 수준이다
      (모션 켜짐: 애니메이션 컨트롤만 갱신, 꺼짐: 갱신 없음)

## 문제가 생기면
- 창이 하얗게만 보이면: `Theme.cs`의 `K`(DPI 배율) 계산이 원인일 수 있습니다.
  `Program.Main`의 `using (Graphics g = Graphics.FromHwnd(IntPtr.Zero)) Theme.K = g.DpiX / 96f;`
  를 확인하세요.
- 글자가 네모(□)로 보이면 Segoe UI/Malgun Gothic이 없는 환경입니다(Windows에서는 정상).
- 애니메이션이 끊기면: 설정에서 모션을 끄고, 원격 데스크톱 여부를 확인하세요.
