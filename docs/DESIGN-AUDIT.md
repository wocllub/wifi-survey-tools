# 무선시그널분석기 UI 진단 — "왜 저렴해 보이는가"

대상: `WifiSignalChecker`(신호 체크, 935줄), `WifiCoveragePlanner`(음영 분석기, 1567줄)
기준: 커밋 `29a35ee` (main)
결론 먼저: 두 프로그램 모두 **직접 그린 카드가 일부 있는데, 그 위에 Windows 기본 컨트롤이 그대로 얹혀 있어서** "만든 사람이 반쯤만 손댄 툴"로 보입니다. 싸구려 인상의 원인은 화려함의 부족이 아니라 **일관성의 부재**와 **상태·움직임의 부재**입니다.

## 2. 화면별 진단

### 2.1 WifiSignalChecker

**(a) 상단 헤더 카드** — `HeaderCard.PaintContent`
- 좌측: 캡션 9.5pt, SSID 21pt, 조언문 9.5pt. 우측: dBm 30pt + 바 5개.
- 문제 1: **숫자가 흔들린다.** 30pt 비례폭 숫자로 매초 다시 그리기 때문에 `-53 dBm` → `-61 dBm`에서 글자 폭이 달라져 값이 좌우로 움직인다. 프리미엄 계측기의 첫 번째 조건은 "숫자가 고정된 자리에서 변하는 것"이다.
- 문제 2: 배경이 순백(#FFFFFF) + 1px 회색 테두리. 화면 전체가 밝아서 값이 튀지 않는다. 조명 낮은 통신실/배선함에서 보는 도구인데 흰 화면은 기능적으로도 불리하다.
- 문제 3: 5개 바가 `lv.Bars` 개수만큼 칠해지는 **정적** 표시. 측정 중이라는 느낌(=이 도구가 살아 있다는 느낌)이 전혀 없다.

**(b) 지표 타일 6개** — `Tile`
- 채널 / 링크 속도 / 공유기 응답 / 패킷 손실 / 규격·보안 / 측정 횟수. 6개가 **동일한 104px 높이, 동일한 16pt 굵은 값**.
- 문제: "패킷 손실 0%"와 "측정 횟수 37회"가 같은 무게다. 정보 위계가 없다.
- 문제: 값이 바뀔 때 이전 값과의 관계(델타)나 추세가 없다. 계측기라면 "아까보다 6 dBm 나빠짐"이 보여야 한다.

**(c) 신호 추이 그래프** — `GraphCard`
- 고정 Capacity 180 × 1초 = "최근 3분"이 하드코딩. 창 길이 선택 불가.
- 꺾은선(`DrawLines`)이고 영역 채움이 없다. 신호 띠는 알파 20이라 사실상 안 보인다.
- Y축 -20 / -100 고정 클립 → -100 이하는 **조용히 잘린다**(표시 오류).
- X축 레이블이 "3분 전 / 지금" 두 개뿐. 측정 시각을 읽을 수 없다.
- 실시간 느낌 없음: 1초에 한 번, 계단처럼 추가.

**(d) 주변 Wi-Fi 목록** — `ListView`
- `BorderStyle.FixedSingle` + `HeaderStyle.Nonclickable` → **정렬 불가**, 기본 회색 3D 테두리, 기본 헤더. 여기가 가장 노골적으로 "기본 컨트롤"이 보이는 지점.
- 선택 행 배경 `Color.FromArgb(232,242,252)`(하드코딩), 현재 연결 AP는 `● ` 문자를 SSID 앞에 붙여 구분 — 아이콘 대신 글머리 기호.
- 호버 상태 없음, 신호 세기가 텍스트 색으로만 표현됨. **막대 그래프로 보여야 할 정보**를 글자로 읽어야 한다.

**(e) 하단 바** — `Panel` + 기본 `Button` 2개(`FlatStyle.System`) + `Label`
- `status.Padding = new Padding(Ui.S(250), 0, 0, 0)`: 버튼과 겹치지 않게 **250px을 손으로 비워 둔** 흔적. 레이아웃이 자동이 아니라 눈대중이라는 증거.
- 기본 시스템 버튼은 OS 버전마다 다르게 보인다(Windows 10/11 혼재). 아이콘 없음.

**(f) 전역**
- `AutoScaleMode.None` + 수동 `Ui.K` 배율. 폰트는 pt로 그대로 → 150% 배율에서 여백만 커지고 글자는 그대로인 불균형.
- 색·여백·폰트가 토큰이 아니라 리터럴 → 테마 변경 = 44곳 수정.

### 2.2 WifiCoveragePlanner

**(a) 좌측 도구 패널** — `BuildLeft`
- `RadioButton { Appearance = Button, FlatStyle = Standard }` 6개를 세로로 32px씩. **이 화면에서 가장 싸구려로 보이는 요소 1순위**. 90년대 옵션 버튼 모양이고, 아이콘이 없어 6줄의 글자를 읽어야 도구를 고를 수 있다.
- 폭 256px 고정 `FlowLayoutPanel` + `AutoScroll`. 항목마다 `Margin(0,0,0,5)` → 5px라는 그리드에 없는 값.
- AP 제품 목록은 기본 `ListBox`(112px). 벤더 → 모델 2단 드롭다운인데, 제조사 색은 `Catalog.VendorColor`로 따로 하드코딩되어 UI 팔레트와 무관한 6색을 쓴다.

**(b) 우측 분석 패널** — `BuildRight`
- `statMain`(20pt 라벨) + `statSub`(여러 줄 문자열 Label) — **숫자와 설명이 한 덩어리 문자열**이라 정렬이 안 된다. 커버리지 %가 화면에서 가장 중요한 숫자인데 20pt 라벨 하나로 끝.
- `AddField`가 2열 TableLayoutPanel(112px/나머지)로 라벨+컨트롤을 붙이는데, 콤보박스는 기본 모양이라 라벨과 높이가 미묘하게 어긋난다.
- AP 속성 패널은 `SetBounds`로 **픽셀 좌표를 직접 계산**(y += 34). 폰트가 커지면 즉시 깨진다.

**(c) 캔버스** — `Scene.Draw`
- 히트맵: 셀 1픽셀 → `Bilinear` 확대. 경계가 뭉개지고, 색 함수가 3점 선형(RGB)이라 중간색이 **탁한 올리브**로 나온다. 알파 145라 전체적으로 바래 보인다.
- 음영 구간: 흰색 120 알파 대각선 해치를 히트맵 위에 덮음 → 정보가 아니라 **노이즈**로 보인다.
- AP 마커: 지름 28px 원 + 흰 테두리 2px + 제조사 머리글자. 선택 시 파란 링. 정적.
- 범례: 도면 **위에** 300×58 흰 사각형을 얹고 1px 테두리. dBm 눈금이 시작/끝 두 개뿐.
- 히트맵 계산은 `ThreadPool` + `debounce 90ms`로 이미 비동기인데, 결과가 **한 프레임에 교체**된다. 도구 성능이 좋다는 인상을 줄 수 있는 지점을 그냥 버리고 있다.
- 축척 미설정·도면 없음·실측 없음 상태에서 **빈 화면에 격자만** 보인다. 안내 없음.

**(d) 크롬** — `MenuStrip`(흰색), `StatusStrip`(기본 3D 그립), 사이드 패널 배경 #F3F5F8. 메뉴/상태바가 카드 톤과 따로 논다.

## 4. 여백·정렬 — 8pt 그리드 없음

- 같은 역할인데 다른 값: 카드 내부 12/14/16/20, 패널 여백 4/10, 버튼 높이 32/36, 타일 높이 104/112.
- 결과: 좌우 카드의 텍스트 시작선이 2~6px씩 어긋난다. 사람은 이걸 "정리가 안 됐다"로 인지한다.

## 5. 타이포그래피 — 11종 폰트 크기, 계층 없음

`8, 8.5, 9, 9.5, 10, 10.5, 14, 16, 20, 21, 30` pt. 전부 `Malgun Gothic`.
- 21pt와 20pt, 9.5pt와 10pt처럼 **구분되지 않는 두 값**이 공존 → 의도가 아니라 즉흥의 흔적.
- 숫자에 고정폭(tabular) 처리가 없어 매초 갱신 시 흔들림.
- 자간(letter-spacing)·대문자 라벨·단위 축소 같은 "계측기 문법"이 없음(단위가 값과 같은 크기로 붙어 있음: `-53 dBm` 전체가 30pt).

## 7. 개선 방향 (이번 작업에서 실제로 적용한 것)

### 7.1 다크 프리미엄 토큰

| 토큰 | 값 | 쓰임 |
| --- | --- | --- |
| `bg` | `#0B0E13` | 창 배경 |
| `surface` | `#12161D` | 카드 |
| `surfaceHi` | `#171D26` | 호버/상승 카드 |
| `border` | `#232A35` | 1px 테두리 |
| `borderStrong` | `#2E3744` | 구분선, 입력 테두리 |
| `text` | `#E9EEF6` | 본문 |
| `textDim` | `#98A4B5` | 보조 |
| `textMute` | `#66717F` | 캡션 |
| `accent` | `#4C8DFF` | **단일 액센트**: 선택·포커스·주 버튼·활성 도구 |
| `accentHi` / `accentLo` | `#6FA6FF` / `#3670D8` | 호버 / 누름 |
| 신호 5단계 | `#11C9A0` `#5FD16A` `#F2C63D` `#FF9A3D` `#FF5D6C` | 도메인 의미색(액센트와 분리) |

여백은 **8pt 그리드**: 4 / 8 / 12 / 16 / 24 / 32 / 48만 사용. 폰트는 5단계(캡션 9, 본문 9.5, 라벨 10.5, 제목 13, 지표 30/44)로 축소.

### 7.2 움직임 (60fps, GPU 합성 가능한 것만)

- `Motion` 러너: 하나의 60fps 타이머가 **애니메이션 중인 컨트롤만** `Invalidate`. 스프링(임계 감쇠) 기반이라 값이 연속으로 들어와도 끊기지 않는다.
- 숫자: `MonoDigits` 고정폭 셀 + 스프링 보간 → 자리가 고정된 채 부드럽게 변함.
- 게이지/링/미터: 목표값으로 트윈, 측정 중 펄스.
- 그래프: 최근 N초 윈도우가 매 프레임 흐르고, Catmull-Rom 보간 + 그라데이션 영역 + 글로우 끝점.
- 히트맵: 좌→우 스윕으로 채워짐, 약전계는 맥동.
- 설정에서 **모션 끄기** 지원(접근성·원격 데스크톱·저사양).

### 7.3 적용 범위

- 공통: `src/Design/Theme.cs`(토큰·타이포·모션·드로잉 헬퍼), `src/Design/Widgets.cs`(카드·KPI·링·스트림 그래프·스펙트럼·데이터 표·버튼·콤보·세그먼트·툴레일).
- 신호 체크: 헤더/타일 → 히어로 카드 + KPI + 링, 그래프 → 라이브 스트림, 목록 → 데이터 표(정렬·검색·신호 막대), 탭(실시간/세션/채널), 세션 기록·재생·오버레이, 간섭 분석, 설정 저장.
- 음영 분석기: 도구 라디오 버튼 → 아이콘 레일, 기본 콤보 → 테마 콤보, 캔버스 다크 팔레트 + 히트맵 스윕 + AP 펄스 + 부유 범례, 분석 결과 → KPI 링 카드, 리포트(HTML/PNG/CSV) 내보내기.

## 8. 남은 제안 (이번 범위 밖)

1. **WPF 또는 WinUI 3로의 이전** — 지금은 GDI+ 즉시 모드라 60fps 애니메이션에 한계가 있다(특히 큰 창). WinUI 3의 합성 애니메이션이면 더 부드럽고, 다크 테마·DPI도 자동.
2. **다국어(ko/en) 전환** — 문자열이 코드에 직접 박혀 있다. 리소스화 + 언어 전환이 다음 단계.
3. **다층 평면도 / 실측 보정** — 층 전환, 두 지점 거리 보정, 측정 지점 스냅.
4. 워터폴(스펙트럼 분석) 뷰 — 현재 API(WLAN_BSS_ENTRY)는 순간 스캔값만 주므로 진짜 워터폴은 별도 드라이버/모니터 모드가 필요. 제안: 채널 점유 스펙트럼(현재 구현)으로 대체하고, 실제 워터폴은 향후 과제로.
